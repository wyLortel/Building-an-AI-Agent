도구 목록을 받은 모델은 두갈래로 응답
도구가 필요없으면 그냥 평소 처럼 텍스트를 담아서 답변하면 됨
하지만 도구가 필요하다면 추가적인 것들을 돌려줌
추가적인건 네임이나 그런것들

{
"type": "function",
"function": {

네임은 나중에 모델이 이 도구를 불러줘 라고 할떄 가르키는 이름
"name" : "calculate",

description(디스크립션)은 이 도구가 무슨일을 하는지에 대한 설명
모델 입장에서는 오직 이부분만을 보고 언제 이도구를 쓸지 판단함
"description": "산술을 계산합니다. 예) '17 \* 23'",

파라메터는 도구가 받을 입력의 형태
expression이란게 있는데 이거는 필수야 리콰이얼드 조건 이라는뜻 리콰이얼 안에 넣음
파라미터는 json스키마라는걸 꼭 명심
"parameters": {
"type":"object",
"properties":{
"expression":{
"type": "string",
"description":"계산할 수식"
}
},
"required": [
"expression"
]
}
}
}
